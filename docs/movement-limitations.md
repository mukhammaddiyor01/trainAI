# Movement Limitation Input Boundary

Reviewed 2026-11-06. The next planning input asks whether the user reports a
movement limitation that could affect exercise selection. It is a self-report,
not a health screening result, diagnosis, clinician clearance, or instruction
to stop all physical activity. No workout is generated by saving this answer.

## Evidence and product decision

- [WHO physical activity guidance](https://www.who.int/initiatives/behealthy/physical-activity/)
  describes adult aerobic activity and muscle strengthening across major muscle
  groups. Its population targets do not specify TrainAI exercise IDs, sets, reps,
  loading, or an appropriate individual schedule.
- [CDC chronic condition and disability guidance](https://www.cdc.gov/physical-activity-basics/guidelines/chronic-health-conditions-and-disabilities.html)
  says people with these conditions can be active and should discuss suitable
  activity types and amounts with a health professional or activity specialist.
  A reported limitation therefore requires an adapted path, not a blanket claim
  that movement is unsafe.
- [CDC getting-started guidance](https://www.cdc.gov/healthy-weight-growth/physical-activity/getting-started.html)
  advises starting slowly and increasing gradually. It does not justify
  automatically assigning volume from a catalog source-level label.

TrainAI will store exactly one of three explicit answers: `unsure`,
`none_reported`, or `needs_adaptation`. There is no default and a blank answer
cannot be interpreted as `none_reported`. The labels state only what the user
reported. `needs_adaptation` does not collect a diagnosis or free-text health
history. Any future automatic workout selection must fail closed when the
answer is missing, unsure, or needs adaptation. Even `none_reported` is not
medical clearance: separate rules for exercise dosage, age scope, equipment,
schedule, recovery, and exercise-specific suitability are still required.

The current six exercise records are source metadata only. Upstream `source_level`
and primary muscles cannot establish safe technique, intensity, or individual
appropriateness. Equipment availability is necessary for a candidate but does
not make it a prescription. WHO's population-level two-day strengthening
guidance is not a default schedule for every saved preference; one available
weekday, limited session duration, or other constraints must remain visible.

## Privacy and implementation sequence

This answer belongs to the signed-in owner. Use plain strict validation first,
then a one-row owner-scoped PostgreSQL record without backfill or a default.
Guarded API and browser collection follow in separate verified increments.
Responses contain only the status. Do not log the choice, send it externally,
include it in AI prompts, or infer it from energy context, training activity,
age, or other saved fields. No existing profile or training preference changes
when this answer is saved.
